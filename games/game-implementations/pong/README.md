    # One Player Pong Game

This is a simple one-player Pong game implemented using Pygame.

## How to Run

1. Ensure you have Python and Pygame installed on your system.
2. Navigate to the `pong` directory.
3. Run the game using the following command:

```sh
python pong.py
```

## Controls

- Use the `UP` arrow key to move the paddle up.
- Use the `DOWN` arrow key to move the paddle down.

## Objective

The objective of the game is to keep the ball from going out of bounds by hitting it with the paddle.

Enjoy the game!
